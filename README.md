# Expense Tracker

A responsive Expense Tracker built using HTML, CSS, and JavaScript.

This application helps users track income and expenses, maintain transaction history, and monitor their current balance. All transaction data is stored locally using the browser's Local Storage API, ensuring persistence across page reloads.

## Features

* Add income and expense transactions
* Delete transactions
* Automatic balance calculation
* Transaction history management
* Local Storage persistence
* Dark Mode support
* Theme persistence across page reloads
* Responsive design for desktop and mobile devices

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API
